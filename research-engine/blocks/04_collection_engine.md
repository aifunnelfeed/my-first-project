## РАЗДЕЛ 2: СИСТЕМА ТЕГИРОВАНИЯ

### 2.1. FACT TAGGING
КОД ДОСТУПА: [FACT_TAGGING_V1]

Каждый факт помечается 4 тегами:

| Тег | Значения | Описание |
|-----|----------|----------|
| **TYPE** | VOC / STAT / COMP / EXPERT / TREND / CASE | Голос клиента / статистика / конкуренты / эксперт / тренд / кейс |
| **SOURCE** | S1-S8 + URL/название | Источник с рангом |
| **RELIABILITY** | ★★★ CONFIRMED / ★★ CROSS-CHECKED / ★ SINGLE / ⚠️ HYPOTHESIS | Подтверждённость |
| **RELEVANCE** | CORE / SUPPORT / CONTEXT | Связь с JTBD/Core Promise |

**ФОРМАТ:**
```
[TYPE:VOC | SOURCE:S2/otzovik.com | RELIABILITY:★★★ CONFIRMED | RELEVANCE:CORE]
"Дословная цитата клиента" — otzovik.com, дата
```

**ПРАВИЛА RELIABILITY:**
- ★★★ CONFIRMED: 3+ независимых источника (TRIPLE SOURCE RULE) ИЛИ рецензированная статья с DOI (S5b)
- ★★ CROSS-CHECKED: 2 источника
- ★ SINGLE: 1 источник
- ⚠️ HYPOTHESIS: логическое следствие, не подтверждено

### 2.2. ПРАВИЛО ТРЁХ ИСТОЧНИКОВ (TRIPLE SOURCE RULE)
КОД ДОСТУПА: [TRIPLE_SOURCE_V1]

Факт = CONFIRMED (★★★) если найден в 3+ НЕЗАВИСИМЫХ источниках.

**НЕЗАВИСИМОСТЬ:**
- Разные платформы (otzovik + vc.ru + reddit = 3 независимых)
- Разные авторы (3 отзыва на одном сайте от разных людей = 3)
- НЕ: перепечатка одного факта (1 исходник → 3 перепечатки = 1)
- НЕ: один эксперт цитируется в 3 статьях = 1

**ОБЯЗАТЕЛЬНО ДЛЯ:**
- STAT используемый как якорный факт
- CASE на котором строится Core Promise
- Факт "too good to be true"

**ДОСТАТОЧНО 1 ИСТОЧНИКА:**
- VOC цитаты (уникальны по определению)
- EXPERT мнение (авторитетный источник)
- Факты с RELEVANCE=CONTEXT

### 3.2. SEMANTIC EXPANSION
КОД ДОСТУПА: [SEMANTIC_EXPANSION_V1]

**ПРОБЛЕМА:** Шаблоны из 3.1 используют терминологию брифа ({ниша}, {продукт}, {проблема}). Аудитория описывает ситуацию СВОИМ языком — бытовыми фразами, жалобами, вопросами из повседневных контекстов.

**РЕШЕНИЕ:** Перед поиском агент разлагает тему на 3-5 жизненных контекстов аудитории и формулирует поисковые запросы на их языке.

**ПРАВИЛА:**
1. **MAX_CONTEXTS: 5.** Не более 5 контекстов. Каждый — конкретная ситуация из жизни ЦА.
2. **2-3 запроса на контекст.** Итого 6-15 дополнительных запросов.
3. **Язык аудитории.** Запросы формулируются так, как спросил бы клиент в поисковике или написал на форуме. НЕ профессиональная терминология.
4. **Контексты специфичны для агента.** A — бытовые ситуации боли/мечты. B — как сравнивают и выбирают. C — смежные области и неочевидные связи.
5. **Интеграция.** Дополнительные запросы используются ВМЕСТЕ с шаблонами из 3.1, не вместо них.

## РАЗДЕЛ 4: ПРОТОКОЛЫ СБОРА

### 4.1. ДЕКОДИРОВАНИЕ АВАТАРА ЧЕРЕЗ JTBD
КОД ДОСТУПА: [JTBD_DECODER]

**1. СМЕРТЬ СОЦДЕМА**
ЗАПРЕЩЕНО опираться только на "Женщина, 35 лет". Один продукт "нанимают" для разных работ:
* Работа 1: Получить повышение (Жадность/Статус)
* Работа 2: Помогать ребенку, не чувствуя себя плохой матерью (Страх/Любовь)
* Работа 3: Смотреть сериалы в оригинале (Развлечение/Комфорт)
Всегда спрашивать: "На какую РАБОТУ клиент нанимает продукт?"

**2. ЧЕТЫРЕ СИЛЫ ПОКУПКИ (THE 4 FORCES)**

A. **PUSH (ТОЛЧОК)** — "Почему мне плохо сейчас?"
Боль текущего момента. Описывать момент максимального раздражения.

B. **PULL (ТЯГА)** — "Как будет хорошо потом?"
Картинка лучшего будущего. 4 слоя глубины:

| Слой | Вопрос | Где искать |
|------|--------|-----------|
| 1. Конкретный результат | Какие измеримые результаты? | Позитивные отзывы, до/после |
| 2. Ценность для жизни | Как изменилась жизнь? | Развёрнутые отзывы |
| 3. Эмоциональная награда | Что чувствуют после? | Эмоциональные фразы |
| 4. Обновление идентичности | Кем себя ощущают? | "Теперь я...", "Больше не..." |

**ПРАВИЛО:** Минимум 2 VOC-цитаты для каждого слоя (если доступны).

C. **ANXIETY (ТРЕВОГА)** — "А вдруг не получится?"
Страхи перед покупкой.

D. **HABIT (ПРИВЫЧКА)** — "Может, и так сойдет?"
Инерция. Цена бездействия.

**3. АРХЕТИПЫ ПРОБЛЕМ**
1. Острая боль (Bleeding Neck): Тон — срочность
2. Хроническая боль (Chronic Pain): Тон — эмпатия, надежда
3. Скрытая угроза (Looming Threat): Тон — предупреждение
4. Стремление к удовольствию (Desire for Gain): Тон — вдохновение

**4. СИМУЛЯТОР АВАТАРА (при нехватке данных)**
1. Что тебя бесит в ситуации прямо сейчас?
2. Чего ты боишься при покупке?
3. Кому ты завидуешь и почему?

### 4.2. МАТРИЦА ШВАРЦА
КОД ДОСТУПА: [SCHWARTZ_MATRIX_V1]

**5 УРОВНЕЙ ОСВЕДОМЛЕННОСТИ:**
1. UNAWARE — "У меня всё хорошо"
2. PROBLEM AWARE — "У меня болит, но не знаю чем лечить"
3. SOLUTION AWARE — "Знаю, что есть массаж, таблетки и йога"
4. PRODUCT AWARE — "Знаю вашу компанию, но дорого"
5. MOST AWARE — "Куда платить?"

**5 УРОВНЕЙ ИСКУШЕННОСТИ РЫНКА:**
1. Девственный рынок → Просто скажите что делает
2. Расширение → Расширить обещание (быстрее, безопаснее)
3. Механизм → Ввести Уникальный Механизм
4. Расширение механизма → Усилить до Большой Идеи
5. Мертвый рынок → Идентификация, стиль жизни

**АЛГОРИТМ:** 1. Определи Awareness → 2. Определи Sophistication → 3. Сформулируй стратегию одним предложением

**ЦЕЛЬ:** Пул конкретных визуальных сцен из жизни ЦА. Используется в SYNTHESIS для распределения по блокам текста.

**МИНИМУМ:** 8 (QUICK), 12 (STANDARD), 15 (DEEP).

| # | Сцена (что происходит) | Контекст (где/когда) | Фраза/мысль | Эмоция | Источник |

5. **SIM-метки.** Сгенерированные сцены — пометка SIM. Максимум 30%.

**WARNING (менее минимума):**
> ⚠️ SCENE_BANK: собрано {N} из {минимум} сцен. Риск повторов образов в тексте.
