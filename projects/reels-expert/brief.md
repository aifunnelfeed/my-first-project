1. Поиск сильной идеи для блога через коучинговые вопросы и практику сериальной самораспаковки
2. Упаковка блога для приближающегося трафика: конвертирующая шапка профиля, хайлайты с воронками и стратегия для закреплённых Reels
3. Написание 10 сильных сценариев для запуска сериальности через личность с помощью готовых шаблонов
4. Анализ роликов: как повторять и усиливать ролики, которые уже залетели. Математический подход для вычисления залетного ролика
5. Где брать идеи для Reels: лайфхак, который почти никто не использует, но генерит идей на месяц вперёд (не ИИ)
