# Бриф: Copycraft Landing Page v2

## Продукт
Copycraft — AI-система (М.О.С. — Маркетинговая Операционная Система) для создания высоконверсионных продающих текстов. Не промпт, а полная методология прямого отклика, реализованная как state machine.

## Формат
Landing page (лонгрид). Целевое действие: запись на живую демонстрацию (30 мин, бесплатно).

## Аудитория
- Владельцы онлайн-школ и инфопродуктов (рус. рынок)
- Маркетологи, которые пишут лендинги / нанимают копирайтеров
- Продюсеры, запускающие экспертов
- Доход бизнеса: от 500K руб/мес
- Уже пробовали ChatGPT для текстов — результат "никакой"

## Проблема аудитории
- Копирайтеры дорого + долго + непредсказуемо
- ChatGPT выдаёт "воду" без структуры и конверсии
- Нет системы: каждый текст — с нуля
- Не могут масштабировать: один лендинг = неделя работы
- A/B тесты делают вслепую, нет базы знаний о том что работает

## Текущее решение аудитории
- Пишут сами (плохо)
- Нанимают фрилансеров (дорого, лотерея)
- Используют ChatGPT / Jasper (generic, без методологии)
- Копируют конкурентов (не понимают почему у тех работает)

## Оффер (на демо)
- 30-минутная живая демонстрация
- Покажу как система за один диалог создаёт лонгрид с конверсией выше рынка
- Разберу один реальный проект участника
- Бесплатно, без обязательств

## Доказательства / пруфы
- Мета-пруф: этот лендинг написан внутри Copycraft
- Метрики результатов по проектам (results.md)
- Скриншоты процесса / скринкаст
- До/после: текст клиента vs текст Copycraft

## Механизм (почему это работает)
- Методология прямого отклика как state machine: ресёрч → стратегия → текст → критика
- Три агента: Researcher + Copywriter + Critic
- Critic не даёт пройти слабому тексту (10 параметров проверки)
- База конверсий: система знает что работает в нише
- Замкнутый цикл: результаты → улучшения

## Тональность
- Уверенная, но без хайпа
- Как инженер объясняет как работает двигатель
- Конкретика и цифры вместо прилагательных
- "Мы не обещаем магию — мы показываем систему"

## Мета-элемент (ключевой)
"Лендинг, который вы сейчас читаете, был создан внутри Copycraft за [время]. Вот скриншот процесса. Это не портфолио — это пруф в реальном времени."
