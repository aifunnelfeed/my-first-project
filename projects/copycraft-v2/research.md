### 1.3. ChatGPT / Claude как конкурент
- 80%+ ЦА уже попробовали ChatGPT для текстов
- Результат: «гладко, но не продаёт»
- Проблема: один промпт = один шаг, нет процесса
- Главная жалоба: «вода», «штампы», «шаблонно», «без конверсии»

### 1.4. Ключевой вывод
**Ни один инструмент на рынке не предлагает методологию прямого отклика.** Все конкуренты — генераторы текста (ввёл промпт → получил текст) или обёртки над LLM. Ни у кого нет:
- State machine с последовательными стейтами
- Разделения на Researcher / Copywriter / Critic
- Обязательной проверки каждого блока
- Замкнутого цикла обучения на результатах

| Агентство | от 40 000 руб | 1-3 недели | Команда |

### 3.2. AI-инструменты

| Категория | Цена | Что получаешь |
|-----------|------|---------------|
| Бесплатные (ChatGPT free, YandexGPT) | 0 руб | Генерация без методологии |

### 3.3. Ценовой gap
**Разрыв:** между «дёшево и бесполезно» (2-5K руб, биржевой текст) и «дорого и долго» (50-100K руб, Senior-копирайтер).
**Позиция Copycraft:** результат уровня Senior за скорость AI. Закрывает именно этот gap.

**Скрытая стоимость текущих решений для ЦА (от 500K/мес):**
- Упущенная выгода за 1-2 недели ожидания копирайтера
- Итерации правок (ещё +3-5 дней)
- Провалившиеся запуски с плохим текстом
- Деньги на трафик, который идёт на неконверсионный лендинг

## 4. «ПРИЕВШИЕСЯ» ОБЕЩАНИЯ (чего избегать)

### 4.1. Красная зона — токсичные формулировки
- «AI-копирайтер» / «нейрокопирайтер»
- «Напишет за вас» / «тексты за минуты»
- «Магия нейросетей» / «сила AI»
- «Заменит копирайтера»
- «10x быстрее» / «в один клик»
- «Автоматический контент» / «генератор продающих текстов»
- «Уникальные тексты» / «100% уникальность»

### 4.2. Жёлтая зона — работает только с контекстом
- «AI-инструмент» — нужна спецификация
- «Нейросеть для маркетинга» — слишком широко
- «Фреймворки» — работает если раскрыть суть

### 4.3. Зелёная зона — дифференцирующие углы
- «Маркетинговая Операционная Система» — не генератор, а среда
- «Методология прямого отклика» — фокус на системе
- «Не пишет за вас — думает вместе с вами»
- «Каждый блок проходит критику»
- «Система, которая не даст вам написать плохой текст»
- «Прямой отклик, а не AI-водичка»

### 4.4. Цифры AI-усталости
- 62% потребителей менее склонны доверять контенту, если знают что он AI
- 50% обеспокоены AI больше чем воодушевлены (было 37% в 2021)
- 42% компаний отказались от AI-проектов в 2025
- Термин «AI slop» — слово 2025 года
- Реальный кейс: контента 3x больше, качество 3x хуже, 20% подписчиков ушли, 40% перестали реагировать
- NielsenIQ: аудитория интуитивно распознаёт AI-креативы, воспринимает как «менее интересные и более раздражающие»

Источники: lgram.ru, vc.ru, Street Fight, NielsenIQ, Rambler&Co

### 4.5. Работающие тренды 2025-2026

| Подход | Почему работает |
|--------|----------------|
| Методология вместо генерации | Устали от «напишет за вас», хотят систему |
| Стратегия, а не текст | «Копирайтинг работает на стратегию, а не на объём» |
| Усиление эксперта, не замена | AI как ассистент, человек как стратег |
| Собственная методология | Аудитория ценит кейсы и уникальный подход |
| Качество над количеством | Меньше контента, но целевого |
| Авторский голос | Узнаваемый стиль, видимая личность |

Источники: Хабр — «Копирайтинг — суперсила 2026», YAGLA — «AI-контент в 2026»

## 5. JTBD-КАРТА

### 5.1. Основные Jobs To Be Done

**Job 1: «Запустить продукт без затыка на тексте»** (Primary Job)
- Push: Лендинг — бутылочное горлышко. Продукт готов, трафик есть, а текста нет.
- Pull: Один диалог — готовый лонгрид уровня Senior-копирайтера.
- Anxiety: «А вдруг AI-текст — такая же вода, как ChatGPT?»
- Habit: «Ну ладно, опять закажу у фрилансера, хотя в прошлый раз было плохо»

**Job 2: «Масштабировать запуски без увеличения команды»** (Growth Job)
- Push: Каждый новый продукт = новый лендинг = новый копирайтер = новая лотерея
- Pull: Система-конвейер, которая работает на любом проекте.
- Anxiety: «Система для всех = шаблон для всех. Моя ниша специфическая.»
- Habit: «У меня уже есть проверенный копирайтер» (который стоит 50K и занят)

**Job 3: «Контролировать качество текстов без экспертизы в копирайтинге»** (Control Job)
- Push: Не могу оценить текст. Плачу деньги и надеюсь. A/B тесты вслепую.
- Pull: Встроенный Критик с 10 параметрами. Система сама проверяет текст.
- Anxiety: «Я не копирайтер — как пойму, что система работает правильно?»
- Habit: «Просто скопирую структуру конкурента»

### 5.2. Четыре силы покупки (сводка)

**PUSH (почему больно сейчас):**
- Копирайтер стоит 50-100K руб и работает 2 недели — результат непредсказуем
- ChatGPT выдаёт «воду» — красиво, но конверсия 0,8%
- Каждый лендинг с нуля, нет накопления знаний
- Запуск стоит из-за текста, деньги на трафик горят

**PULL (как будет хорошо):**
- Лонгрид за 30 минут вместо 2 недель
- Результат уровня Senior-копирайтера
- Система учится на каждом проекте
- Критик проверил = текст рабочий

**ANXIETY (а вдруг):**
- «Очередной AI-хайп, который не работает»
- «Моя ниша слишком специфическая для AI»
- «30 минут = шаблон, не уникальный текст»
- «Бесплатная демо = потом будут продавать»

**HABIT (может и так сойдёт):**
- «У меня есть копирайтер, пусть дорого, но привык»
- «ChatGPT бесплатный, может промпт получше напишу»
- «Скопирую у конкурента, прокатит»

### 5.3. Архетип проблемы
**Хроническая боль (Chronic Pain)** — не острая, но постоянная. Каждый запуск одно и то же: текст — бутылочное горлышко. Тон — эмпатия + надежда.

## 6. «НЕСПРАВЕДЛИВОЕ ПРЕИМУЩЕСТВО» COPYCRAFT

### 6.1. Unfair Advantage
- **State machine из 8 стейтов** — ни один конкурент не имеет пошагового процесса
- **3 агента с разделением ролей** — Researcher не пишет, Copywriter не исследует, Critic не пропускает слабый текст
- **Critic с 10 параметрами** — встроенный контроль качества, которого нет ни у кого
- **Замкнутый цикл обучения** — results.md → каждый текст лучше предыдущего
- **Мета-пруф** — лендинг Copycraft написан Copycraft'ом (невозможно подделать)

### 6.2. Сетка «Кто не может это украсть»

| Утверждение | Конкурент может повторить? | Почему нет |
|-------------|---------------------------|------------|
| 8 стейтов | Нет | Архитектура, а не фича. У конкурентов: промпт → текст |
| 3 агента | Теоретически, но никто не делает | Нужна методология direct response |
| Critic 10 параметров | Нет | Параметры из DR-методологии, нельзя скопировать без знания |
| Мета-пруф | Нет | Лендинг конкурента не написан их AI |
| Замкнутый цикл | Нет | Нужна архитектура results → обучение |

## 8. ФОРМУЛА БОЛИ (для копирайтинга)

### Ситуация «ДО»:
```
Платишь 15-50K копирайтеру → ждёшь 1-2 недели → получаешь «воду» →
→ бесконечные правки → «всё не то» → переделываешь сам →
→ запускаешь что есть → низкая конверсия →
или: просишь ChatGPT → «красивый бессмысленный шум» → снова переделываешь
```

### Ситуация «ПОСЛЕ» (мечта):
```
Загружаешь данные о продукте → система проводит ресёрч →
→ выстраивает стратегию → пишет текст по блокам →
→ сама проверяет (Critic) →
→ готовый лендинг за один диалог → запускаешь → конверсия выше рынка
```
