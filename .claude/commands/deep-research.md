# Deep Research — глубокое итеративное исследование

Ты запускаешь standalone Deep Research — глубокое исследование по конкретной теме с итеративным поиском и in-loop верификацией.

## Аргумент
Тема исследования передаётся как аргумент: `$ARGUMENTS`

Если аргумент пустой — спроси пользователя: **"Какую тему исследуем?"**

## Протокол

### 1. Уточни тему
Покажи пользователю:
```
🔬 DEEP RESEARCH

Тема: {тема из аргумента}
```

Спроси:
- **Глубина:** 15 / 30 / 50 итераций? (по умолчанию: 15)
- **Фокус:** Что именно нужно выяснить? (или "широкий охват")
- **Язык поиска:** RU / EN / оба? (по умолчанию: оба)
- **Сохранить результат?** Если да — куда: `research-engine/projects/{slug}/` или `xrays/`

### 2. Запусти исследование

Используй Agent tool (subagent_type="general-purpose") с промптом:

```
ЗАДАЧА: Проведи глубокое итеративное исследование по теме: "{тема}".

Ты — Deep Researcher. Твой подход:
- Итеративное углубление, где каждый следующий запрос строится на результатах предыдущего
- In-loop верификация: проверяешь факты по ходу, не откладывая на конец
- Журнал каждого цикла для трассировки

ФОКУС: {фокус от пользователя}
ГЛУБИНА: {N итераций}
ЯЗЫК: {RU / EN / оба}

ПРОТОКОЛ ИТЕРАТИВНОГО ПОИСКА:

Работай циклами. Каждый цикл = 3 шага:

ШАГ 1: ЗАПРОС
- Сформулируй WebSearch запрос на основе текущего понимания
- Первый цикл: широкий запрос по теме
- Последующие циклы: уточняющий запрос на основе найденного / пробелов

ШАГ 2: АНАЛИЗ
- Что нового? Что противоречит известному? Где пробелы? Какие новые вопросы?

ШАГ 3: РЕШЕНИЕ
- Уточнить → следующий цикл (уточняющий запрос)
- Верифицировать → следующий цикл (проверочный запрос)
- Новый угол → следующий цикл (exploratory запрос)
- Достаточно данных → следующее направление
- Всё покрыто → СТОП

4 ТИПА ЗАПРОСОВ:
1. EXPLORATORY — широкий поиск
2. DEEP_DIVE — бурение в конкретный факт
3. VERIFICATION — проверка из другого источника
4. CROSS_DOMAIN — связи со смежными областями

КРИТЕРИИ ОСТАНОВКИ (любое):
1. Все направления покрыты
2. Лимит итераций достигнут
3. Последние 3 цикла без нового (diminishing returns)
4. Ключевые факты достигли CONFIRMED (3+ источника)

ФОРМАТ ВЫВОДА:

## DEEP RESEARCH REPORT

### META
- Тема: {тема}
- Фокус: {фокус}
- Циклов: {N}
- Источников: {N}

### КЛЮЧЕВЫЕ НАХОДКИ
| # | Находка | Reliability (★-★★★) | Источники |
|---|---------|---------------------|-----------|

### ВЕРИФИЦИРОВАННЫЕ ФАКТЫ (3+ источника)
1. "{факт}" — {источник1}, {источник2}, {источник3}
2. ...

### ЧАСТИЧНО ПОДТВЕРЖДЁННЫЕ (1-2 источника)
1. "{факт}" — {источник}. Нужно: {что проверить}
2. ...

### ПРОТИВОРЕЧИЯ
| Утверждение A | Утверждение B | Источники | Вероятный ответ |

### ГИПОТЕЗЫ
| Гипотеза | На основе чего | Как проверить |

### ЖУРНАЛ (все циклы)
Цикл 1: {запрос} → {тип} → {нашёл} → {решение}
Цикл 2: ...

### ИСТОЧНИКИ
- {полный список URL}

### ВЫВОДЫ И РЕКОМЕНДАЦИИ
{3-5 ключевых выводов}

ПРАВИЛА:
1. НЕ ПРИДУМЫВАЙ — нет данных = "НЕ НАЙДЕНО"
2. Каждый факт с URL
3. Журнал каждого цикла
4. Верифицируй по ходу (in-loop)
5. 5 циклов без прогресса → СТОП + "DATA SCARCITY"
6. Используй RU + EN запросы
7. Также используй search_knowledge и search_papers через MCP если доступно
```

### 3. Покажи результат

После возвращения агента — покажи пользователю:
```
🔬 DEEP RESEARCH — DONE

Тема: {тема}
Циклов: {N}
Источников: {N}
★★★ Confirmed: {N} фактов
★★ Cross-checked: {N}
★ Single: {N}
⚠️ Hypothesis: {N}
```

Затем покажи полный отчёт.

### 4. Сохранение (если пользователь попросил)

Сохрани отчёт в указанное место. Git commit:
```
research({slug}): deep-research — {тема}, {N} циклов, {N} confirmed
```
