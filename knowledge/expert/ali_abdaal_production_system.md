## 2. IDEA → PUBLISH WORKFLOW (полный pipeline)

### Notion Kanban Board — 8 статусов:

```
No Status → Idea → Writing in Progress → Script Ready for Review → Ready to Film → Filmed → With Editor → Ready for Publication → Published
```

У Ali ~100 идей накоплено в Notion. Pipeline никогда не пустой — нет anxiety "начинать с нуля" каждую неделю.

### Детальный SOP по этапам:

#### ЭТАП 1: IDEA GENERATION (идея)
**Метод ABC:**
- **A — Ask Your Audience**: Спрашивай аудиторию (даже если это друзья/коллеги). Самый простой способ получить больше идей, чем придумаешь сам.
- **B — Birdsong Technique**: Когда потребляешь контент — замечай паттерны, что "звучит" хорошо. Развивай "ухо" для хороших идей.
- **C — (Creative exercises)**: Систематическая генерация.

**Resonance Calendar (Notion):** Каждый раз, когда Ali сталкивается с чем-то, что "резонирует" — статья, видео, книга, подкаст, мысль — он добавляет это в Resonance Calendar. Это база для будущих идей.

**Правило:** Метод ABC работает ТОЛЬКО если есть система хранения идей. Без системы — идеи забываются.

#### ЭТАП 2: RESEARCH & SCRIPTING

**Кто делает:** Scriptwriter (George Blackman был первым, сейчас команда writers).

**George Blackman's Scriptwriting System (5 фаз):**

1. **PREPARE** — глубокий анализ аватара аудитории
2. **BRAINSTORM** — записать ВСЁ, что можно включить в скрипт
3. **STRUCTURE** — сузить, создать robust structure
4. **WRITE** — соединить A→B→C по правилам progression
5. **OPTIMIZE** — редактирование с чеклистом retention-improvements

**Pre-production шаги (из шаблона George):**
- One-sentence idea (одно предложение)
- Talking points brainstorm
- Framing (угол подачи)
- Title + Thumbnail brainstorm (ДО написания скрипта!)
- Targeting your avatar
- Creating structure

**3 уровня скриптования:**
- **Level 0 — No Script**: Только для влогов. Даже Ali пишет хотя бы буллеты.
- **Level 1 — Bullet Points**: Broad-strokes буллет на каждый сегмент, рифф на камеру.
- **Level 2 — Detailed Bullets**: 70-80% качества full script при значительно меньших затратах времени. **Рекомендация для тех, у кого мало времени.**
- **Level 3 — Full Script**: Word-for-word. Каждый сегмент через setup → tension → payoff.

**Совет Ali:** "Для sustainable процесса — Level 2 даёт 70-80% результата."

#### ЭТАП 3: TITLE + THUMBNAIL (до съёмки!)

**Критически важно:** Title и thumbnail разрабатываются ДО съёмки, не после.

**A/B Testing System:**
- Ali постоянно запускает минимум **20 A/B тестов одновременно**
- Инструменты: TubeBuddy (раньше), **ThumbnailTest.com** (сейчас — проще, больше кастомизации)
- Метрики: **CTR** (click-through rate) + **AVD** (average viewer duration)
- Результат: одно видео выросло с 300K до 1.1M просмотров после смены thumbnail

**Процесс:**
1. Brainstorm 5-10 вариантов title
2. Brainstorm 3-5 вариантов thumbnail
3. Выбрать лучшие комбинации
4. Запустить A/B тест после публикации
5. Менять thumbnail/title через несколько часов/дней по данным

#### ЭТАП 4: BATCH FILMING (пакетная съёмка)

**Метод Ali:** Когда работал врачом — снимал **4 видео за 1 день**. Этот ритм построил канал на 6M+ подписчиков.

**Ключевые принципы:**
- **Always-ready setup**: Камера, свет, микрофон всегда настроены. Минимальный friction для начала съёмки.
- **Batch = efficiency**: Снимаешь 1 день — контент на 1-4 недели
- **50% меньше риск выгорания** по сравнению с daily создателями

**Практика:**
- Простые концепты, о которых легко говорить
- Короткий intro (заранее продуманный)
- Говори как с другом — conversational tone

#### ЭТАП 5: POST-PRODUCTION (монтаж)

**Время на монтаж:** ~30 часов на типичное видео Ali Abdaal (до оптимизации).

**Workflow монтажа:**
1. **A-Cut Assembly**: Импорт footage → сборка A-cut через In/Out points → вырезание ошибок и пауз → sharp, snappy edit
2. **B-Roll Addition**: Второй ракурс, titles, transitions, lower thirds, images, screen recordings, handwritten animations
3. **Color & Audio**: Цветокоррекция, звук
4. **End Screen**: Последние 10 секунд — sales pitch / CTA, связь со следующим видео

**AI-ускорение (FireCut):**
- Ali со-создал **FireCut** (plugin для Adobe Premiere Pro и DaVinci Resolve)
- Автоматически: вырезает тишину, добавляет zoom-ins в ключевых моментах, добавляет chapters
- Сокращает время до clean rough cut до **менее 1 часа** (vs 30 часов вручную)

**Software:**
- Раньше: Final Cut Pro X
- Сейчас: **Adobe Premiere Pro** + FireCut
- Субтитры/репёрпозинг: **Subly** (автотранскрипция, субтитры, ресайз для соцсетей)

#### ЭТАП 6: PUBLICATION & REPURPOSING

**SOP загрузки:** В компании Ali есть SOP для ВСЕГО — от загрузки видео до создания Instagram постов.

**Repurposing pipeline:**
1. Видео монтируется в Premiere Pro
2. Прогоняется через Subly → автотранскрипция + субтитры
3. Ресайз в разные форматы для соцсетей
4. Публикация across platforms

**Shorts:** 5-6 фрилансеров делают shorts из long-form контента.

## 4. NOTION SYSTEM (Content Management)

### 3 ключевых элемента:
1. **Kanban Boards** — визуальная организация прогресса контента
2. **Templates** — стандартизированные форматы для каждого типа контента
3. **Linked Databases** — связь между проектами (спонсорский контент ↔ контент-план)

### Content Database:
- Каждая идея = карточка в Notion
- Статусы: No Status → Idea → Writing in Progress → Script Ready for Review → Ready to Film → Filmed → With Editor → Ready for Publication → Published
- ~100 идей всегда в пайплайне
- Properties: тип контента, дедлайн, спонсор (если есть), статус, assignee

### Templates (8+ штук):
- **Video Production Template** — для каждого видео
- **Resonance Calendar** — для захвата идей
- **Book Notes Template** — заметки к книгам
- **Annual Review Template** — годовой обзор
- **Content Calendar** — связан со спонсорскими дедлайнами

### Resonance Calendar:
Отдельная database в Notion. Всё что "резонирует" — статьи, видео, книги, подкасты, мысли — добавляется сюда. Это главный источник для ABC Idea Generation.

## 6. ANALYTICS & ITERATION LOOP

### Метрики отслеживания:
- **CTR** (Click-Through Rate) — главная метрика packaging (title + thumbnail)
- **AVD** (Average View Duration) — главная метрика content quality
- **Views trajectory** — первые 24ч, 48ч, 7 дней
- **Revenue per video**

### A/B Testing Protocol:
1. Публикуй видео с Title A + Thumbnail A
2. Запусти A/B тест через ThumbnailTest.com
3. Через несколько часов/дней — проверь данные
4. Смени на лучший вариант
5. **Всегда минимум 20 тестов одновременно**

### Iteration Process:
- Видео с 300K → 1.1M views после смены thumbnail (конкретный кейс)
- Data-driven decisions, не интуиция
- Continuous optimization — не "set and forget"

## 7. SOP ДЛЯ SOLO CREATOR / МАЛЕНЬКОЙ КОМАНДЫ

### Адаптированный SOP (1 человек):

**Понедельник — Idea + Research (2-3 часа):**
1. Открой Notion → Resonance Calendar → выбери 3 сильные идеи
2. Для каждой: one-sentence idea + talking points brainstorm
3. Выбери 1 лучшую → deep research
4. Brainstorm title (5-10 вариантов) + thumbnail concept

**Вторник — Scripting (3-4 часа):**
1. Structure: setup → tension → payoff для каждого сегмента
2. Write: Level 2 (detailed bullets) если мало времени, Level 3 если есть время
3. Optimize: пройди retention checklist

**Среда — Film (2-3 часа):**
1. Always-ready setup (минимизируй friction)
2. Batch: сними 2+ видео за день если возможно
3. Conversational tone, как с другом

**Четверг — Edit (4-8 часов):**
1. A-Cut: вырежь тишину и ошибки (FireCut для автоматизации)
2. B-Roll: добавь визуальные элементы
3. End Screen: CTA + связь со следующим видео

**Пятница — Publish + Repurpose (2 часа):**
1. Загрузи видео с лучшим title/thumbnail
2. Запусти A/B тест
3. Нарежь 2-3 shorts из long-form
4. Опубликуй shorts + посты в соцсетях

**Суббота-Воскресенье — Capture Ideas:**
- Добавляй в Resonance Calendar всё, что резонирует

### При найме первого человека:
→ **Отдай монтаж.** Это освободит 50-70% твоего времени на creation.

## 10. ПРИНЦИПЫ ДЛЯ КОНТЕНТ-СИСТЕМЫ

1. **System > Willpower**: Построй систему, не полагайся на мотивацию
2. **Batch > Daily**: Пакетная работа эффективнее ежедневной
3. **Delegate bottlenecks**: Аутсорси то, что тебя замедляет (начни с монтажа)
4. **Title/Thumbnail FIRST**: Разрабатывай packaging ДО написания скрипта
5. **Data-driven iteration**: A/B тестируй всё, не полагайся на интуицию
6. **Resonance Calendar**: Всегда захватывай идеи — никогда не начинай с нуля
7. **Sustainable pace**: Level 2 scripting = 70-80% результата при 30% усилий
8. **Always-ready setup**: Минимизируй friction для creative work
9. **Bridge = Email list**: Строй мост между free и paid контентом
10. **Creator ≠ Manager**: Найми integrator/COO если бизнес растёт
