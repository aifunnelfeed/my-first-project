# Copycraft — М.О.С. (Маркетинговая Операционная Система)

AI-ассистент для создания продающих текстов внутри Claude Code.

## Требования

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) CLI
- Python 3.11+
- pip-зависимости (для MCP-сервера базы знаний)

## Установка

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd copycraft

# 2. Установить Python-зависимости
pip install -r requirements.txt

# 3. Настроить путь к Python в .claude/settings.local.json
# Замените путь на ваш:
#   "command": "python3"
# или укажите абсолютный путь к вашему Python 3.11+:
#   "command": "/path/to/your/python3"
```

## Структура проекта

```
├── CLAUDE.md              # Системный промпт (загружается автоматически)
├── blocks/                # 9 модульных блоков инструкций
├── knowledge/             # База знаний (формулы, примеры, материалы)
│   ├── formulas/          # Формулы копирайтинга
│   ├── examples/          # Референсные продающие тексты
│   ├── expert/            # Материалы эксперта
│   └── audience/          # Данные об аудитории
├── projects/              # Проекты (каждый в своей папке)
├── scripts/
│   ├── knowledge_server.py  # MCP-сервер (ChromaDB + embeddings)
│   └── convert_to_md.py     # Конвертер документов в markdown
└── chroma_data/           # Векторная БД (генерируется автоматически, в .gitignore)
```

## Использование

Запустите Claude Code в папке проекта — система запустится автоматически:

```bash
claude
```

При старте Claude:
1. Найдёт проекты в `projects/`
2. Прочитает `state.md` текущего проекта
3. Покажет статус и спросит подтверждение
4. Загрузит нужные блоки инструкций

Для нового проекта скажите: **"Новый проект — {описание}"**

## MCP-сервер (база знаний)

Сервер настраивается в `.claude/settings.local.json`. При первом вызове ленево загружает модель эмбеддингов и индексирует файлы из `knowledge/`.

Инструменты:
- `search_knowledge(query, n_results, category)` — семантический поиск
- `list_sources()` — список проиндексированных файлов
- `reindex(force)` — переиндексация после добавления файлов
