## 1. FLYWHEEL MODEL — Модель перепрофилирования контента

### Основная цепочка (Content Atomization)

```
TWEET (тест идеи)
  ↓ лучшие по engagement
SCRIPT (скрипт для видео)
  ↓ запись
LONG-FORM VIDEO (YouTube, 15-40 мин)
  ↓ нарезка командой
30+ SHORT-FORM CLIPS (TikTok, Reels, Shorts)
  ↓ адаптация
TEXT CONTENT (Twitter threads, LinkedIn posts, carousels)
  ↓ конвертация
BLOG POSTS + EMAIL NEWSLETTERS
  ↓ агрегация
КНИГА (собрание лучших идей)
```

### Точные пропорции

| Вход | Выход | Платформы |
|------|-------|-----------|
| 1 Long-form video | 30+ short clips | TikTok, Reels, Shorts |
| 1 Long-form video | 3-5 mid-length clips | YouTube, Facebook, LinkedIn |
| 1 Long-form video | 5-10 text posts | Twitter, LinkedIn, carousels |
| 1 Long-form video | 1 blog post | SEO / сайт |
| 1 Long-form video | 1 email newsletter | Рассылка |
| **ИТОГО: 1 видео → 40-50 единиц контента** | | |

### Ключевой принцип: Tweet-First Testing

Hormozi сам пишет твиты (без ghostwriter, без AI). Команда собирает лучшие по engagement и превращает их в скрипты для short-form видео. Это **тестирование идей на дешёвом формате** перед инвестицией в дорогой.

### Бизнес-маховик (Content-to-Capital Flywheel)

```
FREE CONTENT (YouTube, подкасты, книги)
  ↓ builds trust & authority
AUDIENCE (7.8M followers, 700K email)
  ↓ generates deal flow
APPLICATIONS (founders $3M-10M revenue)
  ↓ pre-vetted pipeline
PORTFOLIO INVESTMENTS (Acquisition.com)
  ↓ portfolio grows
MORE CASE STUDIES & CONTENT
  ↓ loop
```

**Результат:** портфель компаний генерирует $200M/год в агрегате.

## 2. PRODUCTION SOP — Кто делает что

### Бюджет и команда

- **$70,000/мес** на контент-команду (подтверждено Hormozi)
- **$4,000,000** — стратегия на 2025 год (включая ads для запуска книги)
- Команда: видеографы, редакторы, контент-стратеги, дизайнеры (точное число не раскрыто, оценки 8-14 человек)

### Время Hormozi лично

- **7% времени** на контент (правило "93-7")
- **2 дня в месяц** — запись YouTube видео и shorts
- **4 часа в неделю** — обзор Twitter, mind dumps
- **Ежедневно** — пишет твиты сам

### Workflow (пошагово)

```
ШАГ 1: IDEATION (Hormozi)
├── Ежедневные mind dumps
├── Личные твиты (тест идей)
└── Анализ: какие твиты зашли → скрипты

ШАГ 2: SCRIPT (команда + Hormozi)
├── Лучшие твиты → скрипты short-form
├── Структура: Hook → Hammer/Humor → Read tweet → Example → Explanation
└── Long-form: outline на основе проверенных идей

ШАГ 3: RECORD (Hormozi, 2 дня/мес)
├── YouTube long-form (batch recording)
├── Shorts (batch recording)
└── Talking head — основной формат

ШАГ 4: EDIT (команда)
├── Long-form → YouTube (субтитры, b-roll, zoom-ins)
├── Long-form → 30+ short clips (hooks + captions)
├── Thumbnail design
└── Оптимизация под каждую платформу

ШАГ 5: DISTRIBUTE (команда)
├── YouTube, TikTok, Reels, Shorts, Twitter, LinkedIn
├── Blog adaptation
├── Email newsletter
└── 80+ единиц в неделю (250+ постов/нед на пике)

ШАГ 6: ANALYZE (команда)
├── Какие видео зашли → анализ паттернов
├── Репликация успешных элементов
└── SOPs обновляются на основе данных
```

### SOPs покрывают

- Планирование и скриптинг видео
- Процесс редактирования
- Дизайн thumbnail
- Промоушен после публикации
- Каждый SOP основан на данных — анализ успешных видео → выявление паттернов → репликация

## 3. CONTENT PRINCIPLES — Принципы контент-стратегии

### Философия "Document, Don't Create"

- Не придумывай контент — **документируй свой опыт**
- "Я не даю советы — я делюсь своим опытом, надеясь, что это кому-то поможет"
- Позволяет масштабировать быстро, сохраняя аутентичность

### "Give Away the Secrets, Sell the Implementation"

- Все знания — бесплатно (YouTube, книги, подкасты)
- Монетизация — через done-for-you / done-with-you
- **Знать ЧТО делать ≠ СДЕЛАТЬ** — люди платят за помощь с реализацией
- 200+ часов на бесплатный scaling roadmap (от $0 до $100M)

### Volume Creates Skill

> "You have to start with a lot more volume than you're currently doing because you suck. And so you have to make up for lack of quality with more quantity."

> "The only way to get better is volume, and the only way to get even better than volume is volume × time."

### 5 фаз контент-маркетинга (Hormozi's Framework)

| Фаза | Описание | Частота |
|------|----------|---------|
| 1. CREATE | Постишь хоть что-то, хоть где-то | 1 пост когда-нибудь |
| 2. CONSISTENCY | Нашёл платформу, постишь регулярно | 1 раз в 7 дней |
| 3. OMNIPRESENCE | Постишь надёжно на ВСЕХ платформах | 1 раз/день на каждой |
| 4. VOLUME | Максимум постов на каждой платформе | 5-10/день (short-form), 1/день (feed) |
| 5. SCALE | Capture + Repurpose + команда | 80+ единиц/неделю |

### Стратегический сдвиг (2024-2025)

Hormozi сместил фокус с short-form на **long-form**:
- Long-form привлекает более engaged и relevant аудиторию
- Short-form остаётся для **top-of-funnel** brand awareness
- Long-form → глубина отношений → конвертация в deal flow
- Short-form → ширина охвата → узнаваемость

## 4. VISUAL / EDITING STYLE — Визуальный стиль

### Формат видео

- **Talking head** — основной формат (direct-to-camera)
- **Quick cuts** — нет пауз, нет "воды"
- **Zoom effects** — приближение на ключевых моментах
- **B-roll** — минимальный, для визуального разделения
- **Light flares** — переходы между клипами
- High-energy, direct delivery

### Субтитры / Captions (ключевой элемент)

| Параметр | Значение |
|----------|----------|
| Шрифт | Montserrat Black 900 (или ThBoldFont, Anton) |
| Регистр | ALL CAPS |
| Размер | ~22pt, крупный |
| Позиция | Центр экрана (не внизу!) |
| Обводка | Yellow stroke |
| Тень | Лёгкая |
| Анимация | Pop-in снизу вверх |
| Highlight | Ключевые слова — другой цвет/размер |
| Emoji | Да, для визуального усиления |

### Анимации caption

- Typewriter effect
- Fade-in
- Glitch
- Show right/left
- Rotation на ключевых словах

### Правило 3 секунд

**Первые 3 секунды** — ОГРОМНЫЙ текст на экране. Даже если весь остальной ролик минималистичный, opening sentence должен быть максимально крупным и ярким. Это "visual hook" для остановки скролла.

### Зачем субтитры на каждом слове

- 85% смотрят без звука (mobile)
- Captions = второй канал удержания внимания
- Highlight ключевых слов = управление вниманием зрителя

## 5. HOOK FORMULAS — Формулы хуков

### Framework: Hook → Retain → Reward

Каждая единица контента = 3 части:
1. **Hook** — останови скролл за 1-3 секунды
2. **Retain** — удержи через structure, stories, open loops
3. **Reward** — дай больше ценности, чем ожидали

### 4 типа хуков Hormozi

| Тип | Формула | Пример |
|-----|---------|--------|
| **Bold Claim** | Обещание с конкретной цифрой | "Learn how I built a 7-figure business in under 12 months" |
| **Provocative Question** | Вопрос, вызывающий curiosity | "What if you could double your revenue without spending an extra penny?" |
| **Shocking Stat** | Неожиданный факт/статистика | "Most people are wasting 80% of their marketing budget — and they don't even know it" |
| **Story Opening** | Личная история с интригой | "3 years ago I was sleeping on the gym floor..." |

### Value Equation для хуков

Hormozi использует свою Value Equation для построения viral hooks:
- **Dream Outcome** — какая трансформация? Нарисуй best-case scenario
- **Perceived Likelihood** — почему это сработает?
- **Time Delay** — как быстро результат?
- **Effort & Sacrifice** — как мало усилий?

Хук, который максимизирует Dream Outcome + Likelihood и минимизирует Time + Effort = вирусный.

### Retention тактики

- **One key takeaway per video** — никакого rambling
- **Storytelling** — интеграция историй для engagement
- **Open loops** — тизер будущих пунктов ("But that's not even the biggest mistake...")
- **Секции** — разбивка на мини-блоки
- **Без filler** — каждое предложение несёт value

### Структура short-form (формула)

```
HOOK (вопрос/утверждение/шок) — 1-3 сек
  ↓
HAMMER / HUMOR — усиление хука — 3-5 сек
  ↓
READ THE TWEET (если из твита) — 5-10 сек
  ↓
EXAMPLE — конкретный пример/история — 10-20 сек
  ↓
EXPLANATION — ценность/вывод — 10-20 сек
```

## 6. VOLUME STRATEGY — Стратегия объёма

### Цифры

| Период | Объём контента | Результат |
|--------|---------------|-----------|
| Начало | 7 единиц/неделю | Медленный рост |
| Масштабирование | 80 единиц/неделю | Взрывной рост |
| Пик | 250+ постов/неделю | Ubiquity across platforms |

### Частота по платформам (Phase 4+)

| Тип платформы | Частота | Примеры |
|---------------|---------|---------|
| Short-form | 5-10 постов/день | TikTok, Reels, Shorts, Twitter |
| Feed/newsfeed | 1-2 поста/день | LinkedIn, Facebook |
| Long-form | 1 видео/неделю | YouTube |
| Email | 1-3/неделю | Newsletter |

### Почему объём работает

1. **Больше at-bats** — каждый пост = шанс на viral
2. **Алгоритмы любят частоту** — consistent posting = больше показов
3. **Skill accumulation** — 100 постов научат больше, чем 10 идеальных
4. **Compound effect** — контент не умирает, а накапливается
5. **Occupy mindshare** — если ты везде, тебя невозможно забыть

### YouTube как якорная платформа

- 3,600+ видео на канале
- В среднем 200,000 просмотров на видео
- YouTube = cornerstone (всё остальное — деривативы)

## 8. KEY TAKEAWAYS — Что можно адаптировать

### Для контент-системы Copycraft

1. **Tweet-First Testing** → тестировать идеи в коротких форматах (Threads?) перед производством видео
2. **1 Long → 40+ единиц** → pipeline.md уже заточен под это, но можно усилить конвейер
3. **Hook, Retain, Reward** → применимо к каждому посту, видео, главе книги
4. **93-7 Rule** → автор тратит минимум времени на запись, команда/система делает остальное
5. **SOPs на основе данных** → анализировать что зашло → формализовать в шаблон → реплицировать
6. **Volume × Time** → не 1 идеальный пост, а 10 нормальных
7. **Long-form для конверсии, short-form для охвата** → разные цели для разных форматов
8. **Give secrets, sell implementation** → книга бесплатно раздаёт "как", продукт = помощь в "сделать"
