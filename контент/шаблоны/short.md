# Шаблон: YouTube Short (30-50 сек)

## Типы шортсов

### Тип 1: "Одна мысль" (самый вирусный)
```
[Текст на экране — крупный, 2-3 слова]
↓
Озвучка: "[Контринтуитивное утверждение]"
↓
Объяснение: 15-20 сек
↓
"Полное видео — в профиле / по ссылке"
```

### Тип 2: "Ошибка" (высокий engagement)
```
"[N]% людей делают эту ошибку в [контекст]"
↓
Показать ошибку (3-5 сек)
↓
"Вот как правильно:" (10-15 сек)
↓
"Все ошибки — в полном видео"
```

### Тип 3: "До/После" (наглядный)
```
"Вот текст, который НЕ продаёт:"
[показать плохой пример — 5 сек]
↓
"А вот тот же текст после [техники из главы]:"
[показать хороший пример — 5 сек]
↓
"Как это сделать — в полном видео"
```

### Тип 4: "Нарезка лучшего момента"
```
[Самый яркий фрагмент из Long — 30-40 сек]
↓
Текст на экране: "Полное видео — в профиле"
```

### Тип 5: "Список" (хорошо для Reels/TikTok)
```
"3 способа [сделать X]:"
↓
"Первый: ..." (5-7 сек)
"Второй: ..." (5-7 сек)
"Третий: ..." (5-7 сек)
↓
"Подробнее — полное видео в профиле"
```

---

## Правила

1. **Первый кадр** — текст на экране (крупный, контрастный, 2-4 слова)
2. **Длина** — 30-50 сек (НЕ 60 — оставляем "голод")
3. **Зацикленность** — конец плавно перетекает в начало (или вопрос → ответ в начале)
4. **Субтитры** — всегда (80% смотрят без звука)
5. **Вертикальный формат** — 9:16
6. **Один тезис** — не пытаться вместить всё

## Формулы хуков для шортсов

```
"Вот почему ваш [текст/оффер/заголовок] не работает..."
"Это ошибка, которую делают [N]% [маркетологов/предпринимателей]..."
"[Авторитет] использует эту технику в каждом тексте..."
"Один приём, который увеличивает конверсию в [N] раз..."
"Перестаньте [делать X]. Вот почему..."
"Я потратил [время] на изучение [N текстов]. Вот главный вывод..."
```
