# Шаблон: YouTube Long (15-25 мин)

## Структура скрипта

### 1. ХУК (0:00 — 0:05)
Лучший момент из ролика ИЛИ провокационный вопрос/факт.

```
Формулы:
- "[Шокирующий факт]. И сейчас я покажу почему."
- "Вот ошибка, которая стоит вам [конкретная цифра]. Через 15 минут вы будете знать, как её исправить."
- "[Вопрос, на который хочется узнать ответ]?"
```

> **📌 MrBeast: match clickbait expectations немедленно.** Зритель должен увидеть то, что ожидал из thumbnail/title. Front-load максимум информации + визуалов + энергии. 21M зрителей уходят в первую минуту даже у MrBeast — это ЛУЧШЕ среднего по платформе.
>
> **📌 Hormozi: 4 типа хуков.** Bold Claim ("Вот как я [результат] за [срок]"), Provocative Question ("Что если вы теряете 80% бюджета?"), Shocking Stat (неожиданный факт), Story Opening ("3 года назад я..."). Используй Value Equation: максимизируй Dream Outcome + Likelihood, минимизируй Time + Effort.

### 2. ИНТРО СЕРИИ (0:05 — 0:10)
Единое для всех видео:

```
"Это серия роликов, где я разбираю систему убеждения через текст.
Каждый ролик — отдельная тема, все ролики связаны.
Плейлист — в описании."
```

### 3. ОБЕЩАНИЕ РОЛИКА (0:10 — 0:30)
Что зритель получит к концу видео. Конкретно.

```
"К концу этого видео вы будете знать [конкретный навык/понимание],
и сможете [конкретное действие]."
```

### 4. КОНТЕНТ: Блок A (0:30 — 5:00)
Первый смысловой блок.

**Retention hook перед блоком:**
```
"Но сначала — [неочевидный факт/вопрос], без которого всё остальное бесполезно."
```

Содержание из главы книги (адаптированное для видео).

> **📌 MrBeast: "Crazy Progression" в первые 3 минуты.** НЕ рассказывай линейно — покажи прогресс за несколько этапов быстро. Цель: зацепить и эмоционально инвестировать как можно быстрее. Первый spectacle — на ~3 минуте.

### 5. ИИ-МОСТ (5:00 — 6:30)
Мини-секция: как ИИ меняет этот аспект.

```
"А теперь — как это выглядит, когда подключается ИИ.
[Демо / скриншот / пример из Copycraft]"
```

### 6. КОНТЕНТ: Блок B (6:30 — 12:00)
Второй смысловой блок.

**Retention hook:**
```
"И вот тут начинается самое интересное..."
```

> **📌 MrBeast: Midway Curiosity Bait.** Середина видео (~6 мин) — точка, где уходит большинство зрителей. Здесь нужен второй spectacle — новый поворот, вопрос, открытие. Re-anchor на главный вопрос видео каждые 2-3 минуты.
>
> **📌 MrBeast: Attention Reset каждые 60-90 сек.** 1-секундная пауза тишины перед важным моментом — "перезагружает" внимание. Инженерные допамин-пики на минутах 4, 8, 12.

### 7. КОНТЕНТ: Блок C (12:00 — 18:00)
Третий смысловой блок. Практический пример / кейс / разбор.

### 8. РЕЗЮМЕ (18:00 — 20:00)
3-5 ключевых тезисов. Быстро.

> **📌 MrBeast: НИКОГДА не сигнализируй конец видео.** Как только зритель понимает, что видео заканчивается — retention падает вертикально. Оборви резко и держи энергию высокой до последней секунды. Последние 15 секунд = surprise twist, emotional reveal или final reward. Payoff в конце — обязателен.

### 9. CTA + OUTRO (20:00 — 21:00)

```
PRIMARY CTA: [один из трёх — книга / услуга / waitlist]

"Следующий ролик — [тема]. Он уже в плейлисте."
"Подпишитесь, чтобы не пропустить."

[Эндскрин: ссылка на следующий ролик + плейлист]
```
