# Шаблоны: Посты / Треды / Карусели

## Thread (Threads / X)

### Структура (5-7 постов)

```
ПОСТ 1 (хук):
"[Провокационное утверждение или вопрос]

Тред: ↓"

ПОСТ 2-5 (содержание):
По одной мысли на пост. Каждый — самодостаточен.
Короткие абзацы. Одно предложение = один абзац.

ПОСТ 6 (резюме):
"Итого:
• [тезис 1]
• [тезис 2]
• [тезис 3]"

ПОСТ 7 (CTA):
"Подробнее — в видео: [ссылка]

Если полезно — репост, чтобы больше людей увидели."
```

### Формулы хуков для тредов

```
"[N] ошибок, которые убивают [конверсию/продажи/текст]:"
"Я изучил [N] продающих текстов. Вот что отличает лучшие:"
"Почему [общепринятое мнение] — неправда:"
"Вот как [авторитет/компания] [достигает результат]:"
"Один навык, который стоит прокачать в 2026:"
```

## Карусель (Instagram / LinkedIn)

### Структура (7-10 слайдов)

```
СЛАЙД 1 (обложка):
Заголовок крупно (2-3 строки)
Подзаголовок мелко (1 строка)

СЛАЙДЫ 2-8 (контент):
1 мысль = 1 слайд
Минимум текста (3-5 строк)
Крупный шрифт
Контрастные цвета

СЛАЙД 9 (резюме):
3-5 буллетов — ключевые тезисы

СЛАЙД 10 (CTA):
"Полное видео — ссылка в шапке профиля"
"Сохрани, чтобы не потерять"
```

## Длинный пост (Telegram / Instagram)

### Структура

```
[Хук — 1-2 предложения, вызывающие реакцию]

[Развитие: 1 инсайт из главы, развёрнутый с примером]
3-5 коротких абзацев.
Каждый абзац — 1-2 предложения.

[Вывод / actionable takeaway]

[CTA]: "Подробнее разобрал в новом видео → [ссылка]"
```

### Формулы для Telegram-постов

```
"Вчера разбирал [тему] и понял одну вещь..."
"Вот пример. [Конкретный кейс в 2-3 предложениях]. Почему это сработало? Потому что..."
"Большинство [предпринимателей/маркетологов] думают, что [X]. На самом деле — [Y]."
```

---

## Общие правила для всех форматов

1. **Один пост = одна мысль.** Не пытаться пересказать всю главу
2. **Самодостаточность.** Пост полезен даже без видео
3. **CTA на видео** — в конце, не навязчиво
4. **Адаптация языка** — проще, чем в книге. Разговорный тон
5. **Примеры > теория.** Показывать, а не рассказывать
