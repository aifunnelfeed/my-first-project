# Задачи для ассистента

> Документ для онбординга. Отдать ассистенту вместе с доступами.

---

## Фаза 1: Сразу (с первого дня)

### 1.1 Монтаж Long-видео

**Вход:** raw-файл с камеры + скрипт
**Выход:** готовое видео для публикации

Чеклист:
- [ ] Убрать паузы, слова-паразиты, неудачные дубли
- [ ] Вставить субтитры (CapCut / Captions, Hormozi-стиль: крупный шрифт, 2-3 слова, ключевое слово выделено цветом)
- [ ] Вставить B-roll по таймкодам из скрипта (скриншоты, экран Copycraft, текст на экране)
- [ ] Добавить интро серии (шаблон — 5 сек)
- [ ] Добавить outro + end screen (шаблон)
- [ ] Экспорт: 1920×1080, 30fps, h.264

**Софт:** DaVinci Resolve (монтаж) + CapCut (субтитры)
**Время на задачу:** 2-3 часа на 1 Long

### 1.2 Нарезка Shorts

**Вход:** готовый Long + список таймкодов (отмечаю я)
**Выход:** 3-5 Shorts из каждого Long

Чеклист:
- [ ] Вырезать фрагмент по таймкоду
- [ ] Кроп 9:16 (вертикаль)
- [ ] Субтитры (тот же стиль)
- [ ] Текст-хук на первом кадре (крупный, контрастный)
- [ ] Длина: 30-50 сек (не 60)
- [ ] Проверить зацикленность (конец → начало)

**Софт:** CapCut
**Время на задачу:** 30-40 мин на 1 Short

### 1.3 Превью (thumbnail)

**Вход:** тема видео + шаблон Canva
**Выход:** превью 1280×720

Чеклист:
- [ ] Лицо с эмоцией (кадр из видео или отдельное фото)
- [ ] Крупный текст (3-5 слов максимум)
- [ ] Контрастные цвета по brand guide
- [ ] Читается на мобильном (маленький размер)
- [ ] Нет мелких деталей — только крупные элементы

**Софт:** Canva (шаблон настрою я)
**Время на задачу:** 15-20 мин

### 1.4 Публикация

**Вход:** готовое видео + превью + описание (даю я)
**Выход:** видео опубликовано / запланировано

Чеклист для Long:
- [ ] Загрузить на YouTube
- [ ] Вставить заголовок (из скрипта)
- [ ] Вставить описание по шаблону:
  - Первая строка = хук
  - Ссылки: книга, услуга, waitlist
  - Таймкоды (chapters)
  - Ссылки на все ролики серии (плейлист)
- [ ] Теги (по списку + vidIQ подсказки)
- [ ] Превью загружено
- [ ] End screen настроен (последние 20 сек)
- [ ] Cards добавлены (1-2 штуки по ходу видео)
- [ ] Плейлист выбран
- [ ] Время публикации: по расписанию из контент-календаря

Чеклист для Shorts:
- [ ] Загрузить на YouTube Shorts
- [ ] Заголовок (короткий, с хуком)
- [ ] Дублировать на: TikTok / Reels / VK Clips
- [ ] В описании: "Полное видео →" + ссылка

Чеклист для постов TG:
- [ ] Текст (даю я или адаптация из скрипта)
- [ ] Картинка / видео-фрагмент если есть
- [ ] Ссылка на видео
- [ ] Время: по расписанию

**Доступы:** YouTube Studio, TikTok, Instagram, Telegram (admin), VK
**Время на задачу:** 20-30 мин на Long, 10 мин на Short, 5 мин на пост

## Фаза 2: Через 2-4 недели

### 2.1 Сбор метрик

**Когда:** через 24 часа и 7 дней после публикации
**Куда:** таблица "Метрики" (Google Sheets)

Что записать:
- [ ] Views (24h, 7d)
- [ ] CTR (impressions click-through rate)
- [ ] Average retention %
- [ ] Likes / Comments / Shares
- [ ] Subscribers gained
- [ ] End screen CTR (ключевая метрика!)
- [ ] Источники трафика (browse, search, suggested, shorts feed)

**Где взять:** YouTube Studio → Analytics → конкретное видео

### 2.2 Мониторинг комментариев

**Когда:** ежедневно, 15-20 мин
**Куда:** таблица "Идеи / Backlog"

Что делать:
- [ ] Прочитать все новые комментарии
- [ ] Лайкнуть и ответить на простые (по шаблону)
- [ ] Отметить для меня: вопросы, идеи для видео, негатив
- [ ] Записать идеи из комментов в Backlog
- [ ] Удалить спам

**Правило:** на провокации и хейт не отвечать, только удалять. Спорные вопросы — помечать для меня.

### 2.3 Мониторинг конкурентов

**Когда:** 1 раз в неделю, 30-40 мин
**Куда:** таблица или заметка

Что отслеживать:
- [ ] Новые видео конкурентов (список каналов дам я)
- [ ] Что набрало больше обычного (views vs average)
- [ ] Какие заголовки / превью использовали
- [ ] Темы, которых у нас нет
- [ ] Trending форматы / звуки для Shorts

### 2.4 Адаптация контента

**Вход:** скрипт Long-видео
**Выход:** пост для TG / тред для X

Чеклист:
- [ ] Выделить 1 главный инсайт из видео
- [ ] Написать пост (300-500 слов): хук → инсайт → пример → CTA на видео
- [ ] Черновик треда (5-7 постов): каждый самодостаточен, последний = CTA
- [ ] Отправить мне на проверку

## Фаза 3: Через 1-2 месяца

### 3.1 Черновые скрипты Shorts

**Вход:** Long-видео (готовое)
**Выход:** список предложений (таймкоды + почему этот момент)

Критерии хорошего момента для Short:
- Неожиданный инсайт / поворот
- Эмоциональный момент (удивление, провал, победа)
- Конкретный приём / формула (образовательная ценность)
- До/после (визуальный контраст)
- Фраза-цитата (shareable)

### 3.2 Контент-календарь

**Когда:** каждую пятницу — драфт на следующую неделю
**Куда:** Google Sheets / Notion

Что заполнить:
- [ ] Какой Long выходит в Пн (сериал)
- [ ] Какой Long выходит в Ср (обучение)
- [ ] Какие Shorts на Вт/Чт/Пт (из какого Long нарезаны)
- [ ] Какой пост в Сб
- [ ] Тизер в Вс (к следующему эпизоду)
- [ ] Отправить мне на утверждение

### 3.3 Game State

**Когда:** ежедневно вечером, 5 мин
**Куда:** таблица Game State

Что записать:
- [ ] Какие действия сделаны за день (из списка XP)
- [ ] Посчитать XP (с учётом streak-множителя)
- [ ] Обновить streak
- [ ] Проверить HP (были ли пропуски)
- [ ] Проверить, не разблокированы ли Achievements

## Никогда не делегируется

| Задача | Почему |
|--------|--------|
| Съёмка | Я = лицо канала |
| Финальный скрипт Long | Мой голос, мои истории, моя экспертиза |
| Стратегия (темы, арка сезона, порядок) | Только я знаю общую картину |
| Общение с клиентами | Доверие и конфиденциальность |
| Утверждение заголовков и превью | Я знаю, что работает на моей аудитории |
| Ответы на сложные комментарии | Мой голос = мой бренд |

## Доступы (выдать при старте)

| Сервис | Уровень доступа |
|--------|----------------|
| YouTube Studio | Manager (не Owner) |
| Google Sheets (таблицы) | Editor |
| Canva | Member (шаблоны) |
| TikTok | Co-admin |
| Instagram | Collaborator |
| Telegram-канал | Admin (без удаления канала) |
| Google Drive (raw-файлы) | Editor |
| Notion / Trello (если используем) | Editor |

**Не давать:** пароль от Google-аккаунта, доступ к финансам, Owner-права YouTube.

## Коммуникация

| Что | Как |
|-----|-----|
| Ежедневный отчёт | Сообщение в чат: что сделано, что в процессе, вопросы |
| Готовое видео на проверку | Ссылка на Google Drive + "готово к проверке" |
| Срочный вопрос | Сообщение с пометкой "СРОЧНО" |
| Идеи / предложения | В конце ежедневного отчёта |

**Время ответа:** я отвечаю в течение 2-4 часов (не мгновенно).
