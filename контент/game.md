## HP — здоровье (anti-burnout)

Начинаешь с 5 ❤️. Теряешь за пропуски. Набираешь за стабильность.

### Потеря HP

| Событие | Урон |
|---------|------|
| Пропустил запланированный Long | -1 ❤️ |
| Пропустил 2 дня подряд без контента | -1 ❤️ |
| Пропустил неделю | -2 ❤️ |
| Сломал streak 14+ дней | -1 ❤️ |

### Восстановление HP

| Событие | Лечение |
|---------|---------|
| 7 дней подряд по плану | +1 ❤️ |
| Batch-день (3+ единиц) | +1 ❤️ |
| Опубликовал несмотря на "не хочу" | +1 ❤️ (раз в неделю) |

### 0 HP = Game Over (временный)

Если HP = 0:
1. СТОП. Не публикуешь 2 дня (отдых — обязательный)
2. Пишешь post-mortem: что случилось, почему слился
3. Выбираешь ОДИН формат на неделю (только Short ИЛИ только пост) — облегчённый режим
4. Через неделю — HP восстанавливается до 3 ❤️, streak с нуля

## Правила игры

1. **Честность** — записываешь только то, что реально сделал. Никаких "ну почти".
2. **Ежедневный update** — вечером заполняешь трекер. 30 секунд.
3. **Streak считается** если сделал хотя бы одно действие из таблицы XP.
4. **HP не уходит в минус** — 0 = game over, отдых обязателен.
5. **Gold тратится только из магазина** — нельзя "просто купить себе что-то" без золота.
6. **Квесты берутся по одному** side quest — закончил → берёшь следующий.
7. **Уровень не снижается** — даже после game over. Прогресс не теряется.
