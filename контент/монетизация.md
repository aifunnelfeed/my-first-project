## Ключевой принцип

**Люди не покупают "ИИ-систему для копирайтинга". Люди покупают текст, который продаёт.**

Copycraft — это средство. Результат — конверсия, продажи, деньги.

Всё позиционирование строится от outcome, не от features:
- НЕ: "ИИ с 34 вопросами критика и RMBC-методом"
- ДА: "Система, которая превращает любой продукт в текст, который продаёт"

> **📌 Superfan Economics (Kelly + Jin).**
> Kevin Kelly "1,000 True Fans": 1,000 fans x $100/год = $100K. Li Jin "100 True Fans": 100 fans x $1,000/год = $100K. Ключевая разница: Jin продаёт ТРАНСФОРМАЦИЮ (coaching, access), не информацию. Для Copycraft: книга = информация ($25), SaaS = инструмент ($100-1000/мес), услуга = трансформация ($1,500-10,000). Чем ближе к РЕЗУЛЬТАТУ — тем выше цена.
>
> **📌 Whale Model (из gaming):** 95% аудитории = $0 (free content), 4% = $10-50/мес (SaaS), 0.9% = $50-200/мес (Pro SaaS), 0.1% = $1,000+/мес (VIP retainer). Тебе не нужен миллион подписчиков — нужна воронка, которая находит и конвертирует whales.
>
> **📌 7 принципов суперфанов:**
> 1. Воронка глубины, не ширины — 100 superfans при $1K+/год > 10K casual
> 2. Free content = фильтр — книга 200 стр. находит 0.1%, кто станет superfan
> 3. Transformation pricing — информация ($0-30) < инструмент ($100-1K) < трансформация ($1.5K-10K)
> 4. Own the relationship — email > подписчики YouTube > фолловеры
> 5. Community = moat — SaaS копируется, community нет
> 6. Patience > virality — 1 fan/day = 1,000 за 3 года (Kelly)
> 7. Hybrid model wins — free + book + service + SaaS + community
>

## Канал 1: Done-for-you (услуга) — СЕЙЧАС

### Что продаём
Готовый продающий текст, написанный через систему Copycraft.

### Форматы и ценообразование

| Формат | Что входит | Цена (RU) | Цена (EN) |
|---|---|---|---|
| **Лендинг** | Бриф → ресерч → стратегия → полный текст → отладка | 100-300K руб | $2,000-5,000 |
| **Email-серия** (5-7 писем) | Стратегия → серия → отладка | 50-150K руб | $1,000-3,000 |
| **VSL-скрипт** | Бриф → стратегия → скрипт 15-30 мин → отладка | 150-400K руб | $3,000-7,000 |
| **Пакет "Воронка"** | Лендинг + email-серия + ads | 200-500K руб | $4,000-10,000 |
| **X-ray + рекомендации** | Аудит существующего текста + план исправлений | 30-50K руб | $500-1,000 |

### Как продавать

1. **Через контент:** "Хотите, чтобы я написал текст для вашего бизнеса? Ссылка в описании"
2. **Через X-ray:** Бесплатный аудит → "Вот что не работает → хотите, починим?"
3. **Через книгу:** Читатель понимает систему → понимает объём работы → "лучше закажу"
4. **Через кейсы:** "Конверсия лендинга выросла с 1.2% до 4.8% — вот как"

### Процесс (лендинг услуги)

```
Заявка (форма на сайте)
  → Квалификационный звонок (15 мин): ниша, продукт, бюджет, сроки
  → КП с ценой и сроками
  → Оплата 50% → работа → черновик → правки → финал → оплата 50%
  → Результат: готовый текст + рекомендации по дизайну/вёрстке
```

### Уникальное преимущество (почему дороже фрилансера)

- Не "я пишу текст" → "я использую систему из 11 блоков с 34-вопросным критиком"
- Показать процесс: бриф → ресерч → стратегия → RMBC → критик → отладка
- Гарантия: "Если конверсия не вырастет — переделаю бесплатно" (или soft guarantee)

## Канал 2: Книга — СКОРО

### Модель распространения (по модели Hormozi)

| Формат | Цена | Цель |
|---|---|---|
| **Онлайн (PDF / веб)** | Бесплатно | Максимальный охват, lead magnet, authority |
| **Печатная** | ~1,500-2,500 руб (с доставкой) | Монетизация + физический reminder |
| **Аудио** | Бесплатно (YouTube / подкаст) | Дополнительный канал |

### Почему бесплатно онлайн работает

Hormozi раздаёт "$100M Offers" почти бесплатно ($0.99 Kindle). Результат:
- Книга = лучший lead magnet (фильтрует серьёзных людей)
- Читатель, прочитавший 200 страниц = горячий лид
- Книга продаёт услугу/SaaS лучше любой рекламы

### Воронка от книги

```
Книга (бесплатно онлайн)
  → Email: "Скачайте книгу → введите email"
  → Nurture-серия: 5-7 писем (инсайты, кейсы, X-ray примеры)
  → CTA: услуга ИЛИ waitlist API
  → Upsell: печатная версия с доставкой
```

### Печатная версия — детали

- Платформа: самиздат (Ridero, ЛитРес, или прямая печать)
- В печатную добавить: QR-коды на видео к каждой главе, бонус-главу
- Доставка: СДЭК / Почта России / самовывоз
- Маржа: ~500-1,000 руб с экземпляра

## Канал 3: SaaS (Copycraft API) — БУДУЩЕЕ

### Модель

Когда Copycraft станет доступен через API / веб-интерфейс.

### Тарифы (предварительно)

| Тариф | Цена/мес | Для кого | Что включено |
|---|---|---|---|
| **Starter** | $97 (7,000 руб) | Фрилансер, соло-предприниматель | X-ray (безлимит) + 2 проекта/мес |
| **Pro** | $297 (21,000 руб) | Маркетолог, малый бизнес | Полная система + 10 проектов/мес + KB |
| **Agency** | $997 (70,000 руб) | Агентство, команда | Безлимит + мультипользователь + white-label |

### Freemium-якорь: бесплатный X-ray

**Это ключевой growth hack:**
- Любой может загрузить свой лендинг / текст → получить аудит за 30 секунд
- Результат: оценка /100 + топ-5 проблем + рекомендации
- Конверсия в платный: "Хотите исправить? Подключите Pro"
- Вирусность: люди будут делиться результатами ("мой лендинг получил 42/100, ваш?")

### Waitlist (до запуска)

Что обещаем:
- Ранний доступ
- Скидка на первый год (например, -50%)
- Бета-тестирование с обратной связью

Как собираем:
- CTA в видео: "Copycraft скоро станет доступен. Ссылка на waitlist в описании"
- Лендинг waitlist: email + "какой у вас бизнес" (квалификация)

## Канал 4: Партнёрства и B2B

### Типы партнёрств

| Партнёр | Модель | Потенциал |
|---|---|---|
| **Конструкторы сайтов** (Tilda, GetCourse, ClickFunnels) | Интеграция: "Написать текст для этой страницы" | Миллионы пользователей конструкторов, которые мучаются с текстом |
| **Маркетинговые агентства** | White-label: агентство использует Copycraft, клиент не знает | Агентства масштабируют копирайтинг без найма |
| **Инфобизнесмены** | Done-for-you → кейс → рекомендация | Один кейс с именем = сотни клиентов |
| **Курсы по маркетингу** | Партнёрская программа: курс рекомендует Copycraft | Студенты курсов = наша ЦА |

### Affiliate / реферальная программа

- 20-30% от первого платежа (SaaS) или flat fee за лид (услуга)
- Для блогеров, маркетологов, владельцев курсов
- Инструменты: реферальная ссылка + промокод + баннеры

## Риски и митигация

| Риск | Вероятность | Митигация |
|---|---|---|
| "ИИ-копирайтинг" восприятие как commodity | Высокая | Позиционирование через систему и результат, не через "ИИ пишет" |
| Мало клиентов на услугу | Средняя | Начать с низкой цены / бартера для первых кейсов |
| SaaS долго до запуска | Высокая | Не ждать SaaS — зарабатывать на услуге и книге |
| Конкуренты скопируют подход | Низкая (RU) | Скорость + контент + personal brand = защита |
| Выгорание (контент + услуга + разработка) | Высокая | Фокус: Фаза 1 = только услуга + контент. SaaS — позже |
