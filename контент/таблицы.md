| | | | | | | | | | | | | |

**Ключевые метрики для оптимизации:**
- **CTR** — работает ли превью + заголовок

## Как переносить

### Google Sheets
- Каждая секция = отдельный лист (tab)
- Чекбоксы: Insert → Checkbox
- Условное форматирование: зелёный = done, жёлтый = in progress, красный = overdue
- Формулы: автосумма XP, автосчёт completion rate

### Notion
- Каждая секция = отдельная database
- Тип → select property
- Статусы → status property с 3 группами (Not started / In progress / Done)
- Relations: Эпизод-трекер ↔ Метрики ↔ Книга ↔ Клиенты (связи между базами)
- Календарь-вид для контент-календаря
- Board-вид (канбан) для эпизод-трекера
