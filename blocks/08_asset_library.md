# БЛОК 8: БИБЛИОТЕКА АКТИВОВ (Email + Ads + VSL + Chatbot)

## РАЗДЕЛ 5: БИБЛИОТЕКА АКТИВОВ

### 5.1. ПИСЬМА (EMAIL SEQUENCES) — 5 писем
КОД ДОСТУПА: [EMAIL_SEQUENCE_V1]

**ПИСЬМО №1: РАЗОГРЕВ (Lead + Story)**
Заголовок: Curiosity Lead. Текст (400 слов):
1. Лид (1–2 абзаца)
2. Короткая история (боль → инсайт)
3. Переход: «Завтра расскажу, что изменило всё...»
P.S.: Намек на UMR.

**ПИСЬМО №2: УСИЛЕНИЕ БОЛИ (UMP)**
Заголовок: Problem Lead.
1. Конкретные примеры провалов (цифры)
2. UMP: «Проблема не в [вина клиента], а в [скрытая причина]»
3. «Есть решение. Об этом завтра...»

**ПИСЬМО №3: РАСКРЫТИЕ МЕХАНИЗМА (UMR + Big Idea)**
Заголовок: Secret Lead.
1. Большая Идея
2. Объяснение UMR (шаги/аналогия)
3. Первый кейс/пример
4. «Завтра — как это получить»

**ПИСЬМО №4: ПРОДУКТ + ПЕРВЫЙ ОФФЕР**
Заголовок: Offer Lead.
1. Продукт Ревил
2. Value Stack
3. Первая цена + кнопка
4. «Завтра — финальное предложение»

**ПИСЬМО №5: ФИНАЛЬНЫЙ CLOSE**
Заголовок: Urgency Lead.
1. Краткий обзор ценности
2. Усиленный оффер (бонусы, скидка)
3. Гарантия + срочность
4. Кнопка + P.S. с последним доводом

**АНАТОМИЯ ОДНОГО ПИСЬМА (7-шаговая внутренняя структура):**
Каждое письмо серии следует этой логике:

| # | Элемент | Задача |
|---|---------|--------|
| 1 | **Hook** | Первая строка — обещание или провокация. Задача: заставить читать дальше |
| 2 | **Mechanism Tease** | Намёк на UMR без полного раскрытия. «Есть способ, о котором мало кто знает...» |
| 3 | **Benefit Stack** | 2–3 конкретных выгоды с цифрами. Формат: «Вы получите [результат] за [срок]» |
| 4 | **Objection Removal** | Снятие 1 ключевого возражения для данного письма (каждое письмо снимает новое) |
| 5 | **Specificity Anchor** | Конкретная деталь, цифра или мини-кейс — якорь доверия |
| 6 | **CTA** | Одно конкретное действие. Кнопка или ссылка |
| 7 | **P.S.** | Дополнительный крючок: бонус, срочность или социальное доказательство |

**ПРАВИЛО:** Не каждый элемент обязателен в каждом письме. Но Hook (1) + CTA (6) — всегда.

### 5.2. КРЕАТИВЫ (ADS)
КОД ДОСТУПА: [ADS_ENGINE_V1]

**СТРУКТУРА (50–150 слов):**
1. Заголовок: 7–12 слов (Curiosity + Benefit)
2. Подзаголовок: 1–2 предложения (боль или UMR)
3. Текст: 3–5 строк (намек на Механизм)
4. Кнопка CTA: конкретное действие + выгода

**ШАБЛОНЫ ПО ПЛАТФОРМАМ:**

ВКонтакте / Facebook:
[ЗАГОЛОВОК: Почему ваши запуски сливают?]
[ПОДЗАГОЛОВОК: Проблема не в креативах.]
Потому что вы продаете не ту работу ЦА.
[КНОПКА: Узнать метод бесплатно]

Яндекс.Директ / Google:
[ЗАГОЛОВОК: Воронки не окупаются?]
Стандартная ошибка 90% маркетологов. [UMR] дает ROI 2.8+.
[КНОПКА: Получить фреймворк]

Telegram:
[ЗАГОЛОВОК: Секрет ROI 3.2 на холодном трафике]
Не креативы. Не таргет. Метод [UMR].
[КНОПКА: Смотреть разбор]

**АДАПТАЦИЯ:**
* Холодный трафик: Лид + намек на секрет
* Теплый: Лид + мини-оффер
* Ретаргетинг: Срочность + цена

По умолчанию: 2 заголовка + 1 текст. 3+2 — только если тестируем гипотезы.

### 5.4. ЧАТ-БОТЫ И МЕССЕНДЖЕРЫ
КОД ДОСТУПА: [CHATBOT_V1]

**СТРУКТУРА ДИАЛОГА (7 шагов):**
1. Приветствие + Хук
2–4. Интервью (3 вопроса)
5. Мини-диагноз: «Твоя проблема — [UMP]. Решение — [UMR]»
6. Персональный оффер
7. Close: «Осталось 2 места. Кнопка ниже»

**ПРАВИЛА:** 1 вопрос/факт на сообщение | Эмодзи sparingly | Выбор «1 или 2?» | Таймер на финальный оффер

### 5.5. МАТРИЦА ТЕМ ПИСЬМА (SUBJECT LINE MATRIX)
КОД ДОСТУПА: [SUBJECT_LINE_MATRIX_V1]

**ЦЕЛЬ:** Генерация вариантов тем для email по 15 углам. Каждый угол — это отдельная «линза» на один и тот же оффер.

**15 УГЛОВ:**

| # | Угол | Что использовать | Пример (рус) |
|---|------|-----------------|-------------|
| A | **Promise** | Главное обещание результата | «Как удвоить доход без увольнения» |
| B | **Problem** | Боль, усиленная деталями | «Устали выбирать между отпуском и оплатой кружков?» |
| C | **New Cause** | Новая причина проблемы | «Почему ваши диеты не работают (новое исследование)» |
| D | **Mechanism** | Название механизма/метода | «"Арбитражная формула" — как это работает» |
| E | **Old Remedy Wrong** | Старое решение оказалось вредным | «Бег по утрам разрушает ваши колени (делайте это вместо)» |
| F | **Taboo = Solution** | Табу/проблема на самом деле — решение | «Почему "лень" может быть вашим суперсилой» |
| G | **Emotion** | Доминирующая эмоция аудитории (DRE) | «Хватит чувствовать себя обманутым» |
| H | **Story** | Мини-история в теме | «Спор с женой привёл к бизнесу на $7,200/мес» |
| I | **Conflict** | Конфликт, скандал, заговор | «Почему фитнес-индустрия вам врёт» |
| J | **Normal Solution Problems** | Проблемы стандартных решений | «Почему 90% онлайн-курсов — пустая трата денег» |
| K | **People** | Конкретные люди, группы | «Что делают топ-1% предпринимателей в кризис» |
| L | **Topical** | Актуальная новость / тренд | «После новых санкций — 3 способа защитить доход» |
| M | **Believability** | Конкретика, вызывающая доверие | «14,954 человека уже используют этот метод» |
| N | **Urgency** | Срочность, дедлайн | «Осталось 6 часов — потом цена x2» |
| O | **Targeted** | Обращение к конкретному сегменту | «Для мам, которые работают из дома» |

**ПРОЦЕСС:**
1. Возьми оффер / ключевое сообщение
2. Заполни минимум 5 углов из 15
3. Выбери 3 лучших → напиши по 2–3 варианта на каждый
4. Итого: 2 финалиста для A/B теста

**ПРАВИЛО:** Тема письма ≤ 50 символов для мобильных. Прехедер — дополняет, не повторяет тему.
