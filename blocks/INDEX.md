# ИНДЕКС БЛОКОВ — М.О.С. (Маркетинговая Операционная Система)

## Как использовать

В каждом новом чате говори: **"Прочитай блок [номер] и [задача]"**
Загружай только те блоки, которые нужны для текущего шага.

---

| # | Файл | Что внутри | Когда нужен |

## Рекомендуемые комбинации по задачам

### Начало нового проекта (сбор данных):
→ Блоки: **01 + 04** (~8k токенов)

### Ресерч аудитории:
→ Блоки: **01 + 05** (~8k токенов)

### Построение стратегии:
→ Блоки: **01 + 03 + 06** (~10k токенов)

### Написание текста (лендинг/VSL/письмо):
→ Блоки: **02 + 07** (~10k токенов)

### Написание текста (конкретный формат):
→ Блоки: **02 + 08** (~8k токенов)

### Проверка и отладка:
→ Блоки: **09** (~2k токенов)

## Типичный workflow по чатам

**Чат 1:** Блоки 01+04 → INPUT + QUERY (собрать данные)
**Чат 2:** Блоки 01+05 → RESEARCH (если нужен ресерч)
**Чат 3:** Блоки 01+03+06 → STRATEGY (стратегия)
**Чат 4:** Блоки 02+07 → EXECUTION BRIEF (каркас)
**Чат 5:** Блоки 02+07 → EXECUTION COPY (блок Lead)
**Чат 6:** Блоки 02+07 → EXECUTION COPY (блок Story + Mechanism)
**Чат 7:** Блоки 02+07 или 02+08 → EXECUTION COPY (Offer + Close)
**Чат 8:** Блок 09 → DEBUGGING + DELIVERY
