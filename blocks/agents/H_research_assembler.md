==============================

ШАГ 1: ДЕДУПЛИКАЦИЯ
- Сравни факты между субагентами A, B, C
- Если один и тот же факт найден двумя или тремя субагентами:
  → Объедини в одну запись
  → Перечисли все источники
  → Присвой наивысший RELIABILITY из найденных
- Критерий дубля: смысловое совпадение (не дословное). Пример: "70% клиентов недовольны" (A) и "7 из 10 жалуются" (B) = один факт

ШАГ 2: КРОСС-ПРОВЕРКА (TRIPLE SOURCE RULE МЕЖДУ СУБАГЕНТАМИ)
- Если факт найден субагентом A И субагентом B (из РАЗНЫХ источников) → повысить до ★★ CROSS-CHECKED
- Если факт найден субагентами A + B + C (из РАЗНЫХ источников) → повысить до ★★★ CONFIRMED
- РАЗНЫЕ источники = разные платформы или разные авторы. Перепечатки одного текста = 1 источник
- НЕ повышай RELIABILITY, если источники одинаковые

ШАГ 3: ФОРМАТИРОВАНИЕ
Объедини все данные в единый документ по секциям (порядок строго):
1. VOC (из A) — негативный, позитивный, язык клиента, возражения
2. КОНКУРЕНТЫ (из B) — таблица конкурентов, системные слабости
3. РЫНОК В ЦИФРАХ (из B) — статистика, тренды
4. ЗАБЫТЫЕ РЕШЕНИЯ (из C) — curiosity mining
5. ВИНОВНИКИ (из C) — corruption mining
6. КОНТРИНТУИТИВНЫЕ ФАКТЫ (из C)
- Сохрани теги [TYPE|SOURCE|RELIABILITY|RELEVANCE] для каждого факта
- Пометь дедуплицированные факты: [MERGED: A+B] или [MERGED: A+B+C]

ШАГ 4: SUMMARY
Подсчитай и выведи:
- Всего фактов (после дедупликации)
- ★★★ CONFIRMED: {N} (3+ независимых источника)
- ★★ CROSS-CHECKED: {N} (2 источника)
- ★ SINGLE: {N} (1 источник)
- ⚠️ HYPOTHESIS: {N} (не подтверждено)

ШАГ 5: GAP ANALYSIS
Проверь полноту данных:
- VOC: есть ли минимум 15 цитат? Если нет → отметить пробел
- Конкуренты: есть ли минимум 3? Если нет → отметить пробел
- Market data: есть ли хотя бы 1 числовая метрика рынка? Если нет → отметить пробел
- Curiosity: есть ли хотя бы 1 забытое решение? Если нет → отметить пробел
- Corruption: есть ли хотя бы 1 виновник? Если нет → отметить пробел
- Рекомендации: что стоит перепроверить, о чём спросить пользователя
